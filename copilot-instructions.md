# Инструкции для Copilot

## Общие правила взаимодействия

### Язык
- **Всегда общайся на русском языке**. Все ответы, комментарии и объяснения должны быть на русском.
- Используй неформальный, дружелюбный тон.

### Рабочий процесс
- Синхронизируй все изменения с проектом после каждого завершения задачи.
- Создавай Git коммиты с понятными сообщениями на русском после значительных изменений.
- Сохраняй все наработки в соответствующих папках проекта.

### Структура проекта
```
Codex/
├── BT/                    # Требования (Business Tasks)
├── design-system/         # Компоненты дизайн-системы
├── prototypes/            # Интерактивные прототипы
├── README.md
└── copilot-instructions.md
```

## Рекомендации по работе

### При создании файлов
- Используй понятные имена на английском (но комментарии и документация на русском)
- Добавляй комментарии на русском в код
- Создавай README файлы для объяснения структуры

### При редактировании кода
- Проверяй синтаксис перед завершением
- Убеждайся, что изменения не ломают существующий функционал
- Добавляй краткие описания того, что было изменено

### При работе с Git
- Коммиться часто с ясными сообщениями
- Сообщения коммитов на русском, в формате: `тип: описание`
  - `feat: новая функция`
  - `fix: исправление ошибки`
  - `refactor: рефакторинг кода`
  - `docs: обновление документации`
  - `style: форматирование и стиль`

### При разработке прототипов
- Используй современные технологии (HTML5, CSS3, ES6+)
- Делай интерфейсы адаптивными для мобильных устройств
- Добавляй понятные комментарии в коде

## Контекст проекта
Это проект для разработки HR системы с прототипами интерфейсов и дизайн-системой.
Приоритет: функциональность, удобство использования, масштабируемость.

---

**Помни:** Все изменения должны быть задокументированы и закоммичены в Git!
