# Codex - HR система

Проект для разработки интерактивных прототипов и компонентов HR-системы.

## Структура проекта

```
Codex/
├── BT/                    # Требования и спецификации (Business Tasks)
│   └── BT-001.md         # Заявка на отпуск
├── design-system/         # Компоненты дизайн-системы
├── prototypes/            # Интерактивные прототипы
│   └── BT-001/           # Прототип заявки на отпуск
│       ├── index.html
│       ├── styles.css
│       └── script.js
├── README.md              # Этот файл
└── copilot-instructions.md # Инструкции для разработки
```

### Работа с Git
```bash
# Просмотреть статус
git status

# Добавить файлы
git add .

# Создать коммит
git commit -m "feat: описание изменений"

# Просмотреть историю
git log --oneline
```

## Требования

- Браузер с поддержкой HTML5 и CSS3
- Git для версионирования
- VS Code или другой текстовый редактор

## Разработка

При добавлении новых прототипов:
1. Создай папку в `prototypes/` с названием BT-XXX
2. Добавь HTML, CSS и JavaScript файлы
3. Обнови этот README
4. Закомми изменения в Git
