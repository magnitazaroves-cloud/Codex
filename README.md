# Codex - HR система

Проект для разработки интерактивных прототипов и компонентов HR-системы.

## Структура проекта

```
Codex/
├── BT/                    # Требования и спецификации (Business Tasks)
│   └── BT-001.md         # Заявка на отпуск
├── design-system/         # Компоненты дизайн-системы
├── prototypes/            # Интерактивные прототипы
│   └── BT-001/           # Прототип заявки на отпуск
│       ├── index.html
│       ├── styles.css
│       └── script.js
├── README.md              # Этот файл
└── copilot-instructions.md # Инструкции для разработки
```

## Дизайн-система

Полная дизайн-система приложения ТвойМагнит находится в папке `design-system/`:

- **DESIGN_SYSTEM.md** — Полная документация (цвета, типография, компоненты)
- **design-system.css** — CSS переменные и готовые классы
- **EXAMPLES.md** — Примеры использования компонентов

### Основные цвета
- **Primary**: #9747FF (фиолетовый)
- **Secondary**: #ECECEC (светло-серый)
- **White**: #FFFFFF
- **Black**: #000000

[Подробнее о дизайн-системе →](design-system/DESIGN_SYSTEM.md)

## Разработка

При добавлении новых прототипов:
1. Создай папку в `prototypes/` с названием BT-XXX
2. Добавь HTML, CSS и JavaScript файлы
3. Используй дизайн-систему из `design-system/design-system.css`
4. Обнови этот README
5. Закомми изменения в Git
